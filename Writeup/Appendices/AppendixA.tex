\chapter{4DEnVar Method} % Main appendix title

Another way to assimilate observations from multiple times is the 4DVar method. This method uses a form of the cost function from equation \ref{eqn:cost3d}, augmented to include multiple observations. Let $t = 0,1,\dots,T$ be the observation times, then we define the model operator  $\mathcal{M}_{0 \rightarrow t}$ such that the state predicted by the model at time $t$ is related to the state at time 0 by $\x_t = \mathcal{M}_{0 \rightarrow t}\x_0$. The 4DVar cost function then has the form

\begin{equation}
J\left(\x_0\right) = \frac 1 2 \norm[\mat{B}_0^{-1}]{\x_0 - \x_b}^2 + \frac 1 2 \sum_{t=0}^T \norm[\mathbf{R}_t^{-1}]{\y_t - \mathbf{H}_t\mathcal{M}_{0 \rightarrow t}\x_0}^2
\label{eqn:cost4d}
\end{equation}

or equivalently

\begin{equation}
J\left(\vect{\delta_0}\right) = \frac 1 2 \norm[\mat{B}_0^{-1}]{\vect{\delta_0}}^2 + \frac 1 2 \sum_{t=0}^T \norm[\mathbf{R}_t^{-1}]{\y_t - \mathbf{H}_t\mathcal{M}_{0 \rightarrow t}\left( \x_b + \vect{\delta_0} \right)}^2
\label{eqn:cost4d}
\end{equation}

Where $\vect{\delta}_0 = \x_0 = \x_b$. In this cost function, the observations $\y_t$ and matrices $\mathbf{H}_t,\mathbf{R}_t$ are valid at time $t$. Note here that $\x_0$ is a non-augmented state vector containing values only from time 0.

The above equations are valid fo a single deterministic forecast. If an ensemble is available4DEnVar is a variant of 4DVar in which a control variable transform is used to write $\x_0$ as a linear combination of the ensemble perturbations:

\begin{align*}
\mat{X}'_b &= \frac{1}{\sqrt{N- 1}} \left( \x^f_1 - \overline{\x}^f, \x^f_2 - \overline{\x}^f, \dots, \x^f_N - \overline{\x}^f \right) \\
\x_0 &= \overline{\x}_b + \mat{X}'_b \mat{w}_0
\end{align*}

Where $\overline{\x}^f$ and $\mat{X}^f$ are defined in equation \ref{eqn:CVT}. The cost function can then be rewritten in terms of $\mathbf{\chi}$ and simplified by linearising $\mathbf{M}_{0 \rightarrow t}$ around $\overline{\x}^f$:

\begin{equation}
J(\mathbf{\chi}) = \frac 1 2 \norm{\mathbf{\chi}}^2 + \frac 1 2 \sum_{t=0}^T \norm[\mathbf{R}_t^{-1}]{\y_t - \mat{H}_t\mat{M}_{0 \rightarrow t}\left(\overline{\x}^f + \mathbf{X}^f \mathbf{\chi}\right)}^2
\end{equation}

This cost function has been simplified by taking a background error covariance matrix of the form $\mathbf{B} = \mat{X}^f\mat{X}^{f\top}$, which reduces to the identity under the control variable transform. Note that this is identical to the forecast error covariance matrix used in ETKF. This cost function has gradient

\[
\nabla J(\mathbf{\chi}) = \mathbf{\chi} + \sum_{t=0}^T\left(\mathbf{\hat{H}}_t \mathbf{X}'_b\right)^\top \mathbf{R}_t^{-1} \left(\mathbf{\hat{h}}_t \mathbf{X}'_b \chi + \mathbf{\hat{H}}_t \overline{\x}_b - \y_t\right)
\]

A major advantage of this formulation is that we can make the approximation

\[
\mathbf{M}_{0 \rightarrow t} \left( \x^{(n)}_b - \overline{\x}_b \right) \approx \mathcal{M}_{0 \rightarrow t} \left( \x^{(n)}_b \right) - \overline{\mathcal{M}_{0 \rightarrow t} \left( \x_b \right)}
\]

Since $\mathbf{H}_t \mathbf{M}_{0 \rightarrow t} \left( \x^{(n)}_b - \overline{\x}_b \right)$ is the $n^{\text{th}}$ column of $\mathbf{\hat{H}}_t \mathbf{X}'_b$, this approximation allows us to compute the cost function and its gradient without a tangent linear or adjoint model, which is a computationally expensive aspect of most variational data assimilation schemes \citep{Bannister2017}.
